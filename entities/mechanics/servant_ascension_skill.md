# FGO 从者养成系统

> 来源：atlasacademy/fgo-docs + Mooncell + FGO Wiki | 最后更新：2026-07-23


## 一、从者养成总览

从者养成包含以下维度：

| 养成项 | 说明 | 影响 |
|---|---|---|
| **等级提升** | 使用种火（经验值道具）提升等级 | 基础数值提升 |
| **灵基再临** | 消耗素材突破等级上限（共 4 次） | 解锁更高等级、新立绘、新技能 |
| **技能强化** | 消耗素材提升技能等级（Lv.1→Lv.10） | 技能效果提升、冷却时间缩短 |
| **宝具强化** | 消耗同名从者提升宝具等级（NP1→NP5） | 宝具伤害/效果提升 |
| **附加技能** | 消耗素材和从者硬币解锁附加技能 | 额外技能效果 |
| **羁绊提升** | 通过战斗积累羁绊值（上限 Lv.15） | 解锁资料、羁绊礼装、从者硬币 |


## 二、等级提升（种火）

### 2.1 种火类型

| 种火类型 | 经验值 | 稀有度 | 用途 |
|---|---|---|---|
| **★1 种火** | 1,000 | 1★ | 初期升级 |
| **★2 种火** | 3,000 | 2★ | 中期升级 |
| **★3 种火** | 10,000 | 3★ | 中后期升级 |
| **★4 种火** | 30,000 | 4★ | 高效升级 |
| **★5 种火** | 100,000 | 5★ | 最高效 |

### 2.2 等级上限与所需经验

| 星级 | 初始等级 | 灵基再临后最大等级 | 升满所需经验 |
|---|---|---|---|
| **1★** | 1 → 60 | 70（满破） | 较低 |
| **2★** | 1 → 65 | 75（满破） | 中低 |
| **3★** | 1 → 70 | 80（满破） | 中 |
| **4★** | 1 → 80 | 90（满破） | 较高 |
| **5★** | 1 → 90 | 100（满破） | 高 |

### 2.3 种火获取方式

- 种火本（每日任务，AP 消耗）
- 活动兑换
- 友情点召唤
- 限时活动奖励


## 三、灵基再临（突破）

### 3.1 灵基再临概述

- 从者每 10 级需要进行一次灵基再临（突破）
- 共 4 次再临（第 1 次至第 4 次）
- 每次再临需要消耗特定素材和 QP
- 再临后等级上限提升，解锁新立绘

### 3.2 灵基再临素材

以 5★ 从者为例：

| 再临次数 | 所需素材 | QP |
|---|---|---|
| **第1次（50级）** | 棋子 ×5 + 素材 ×10 | 100,000 |
| **第2次（60级）** | 棋子 ×12 + 素材 ×10 | 300,000 |
| **第3次（70级）** | 棋子 ×5 + 素材 ×10 | 1,000,000 |
| **第4次（80级）** | 棋子 ×12 + 素材 ×10 | 3,000,000 |

> **说明**：具体素材和数量因从者而异，请以游戏内数据为准。

### 3.3 灵基再临次数与等级上限

| 再临次数 | 等级上限 |
|---|---|
| **未再临** | 初始最大等级 |
| **第1次** | 60 |
| **第2次** | 70 |
| **第3次** | 80 |
| **第4次** | 90（5★）/ 80（4★）/ 70（3★） |


## 四、技能强化

### 4.1 技能强化概述

- 每个从者拥有 3 个主动技能
- 技能等级从 Lv.1 提升至 Lv.10
- 每级提升需要消耗素材和 QP
- 技能等级提升影响：
  - **效果数值**（如 30% → 50%）
  - **冷却时间缩短**（如 7 → 5 回合）
  - **新增效果**（部分技能在特定等级解锁新效果）

### 4.2 技能升级消耗

| 技能等级 | QP | 素材 |
|---|---|---|
| **Lv.1→2** | 100,000 | 辉石 ×5 |
| **Lv.2→3** | 200,000 | 辉石 ×12 |
| **Lv.3→4** | 400,000 | 魔石 ×5 |
| **Lv.4→5** | 800,000 | 魔石 ×12 |
| **Lv.5→6** | 1,600,000 | 秘石 ×5 |
| **Lv.6→7** | 3,200,000 | 秘石 ×12 + 素材 ×5 |
| **Lv.7→8** | 6,400,000 | 素材 ×10 |
| **Lv.8→9** | 12,800,000 | 素材 ×20 |
| **Lv.9→10** | 25,600,000 | 传承结晶 ×1 |

> **说明**：具体素材因从者而异，请以游戏内数据为准。

### 4.3 技能冷却时间

技能冷却时间随等级提升而缩短：

| 技能等级 | 冷却时间 |
|---|---|
| **Lv.1** | 初始冷却（如 8 回合） |
| **Lv.6** | 初始冷却 -1 回合 |
| **Lv.10** | 初始冷却 -2 ~ -3 回合 |

**示例**：初始冷却 8 回合 → Lv.10 时 6 回合


## 五、宝具强化（宝具升级）

### 5.1 宝具强化方式

| 方式 | 说明 | 效果 |
|---|---|---|
| **同名从者强化** | 消耗同名从者进行宝具强化 | 宝具等级 +1 |
| **从者硬币解锁** | 使用从者硬币进行宝具强化 | 宝具等级 +1（需消耗硬币） |

### 5.2 宝具等级提升

- 初始：**NP1**
- 最高：**NP5**
- 每次提升：消耗同名从者 ×1 或 从者硬币 ×X

### 5.3 宝具强化效果

| 宝具等级 | 效果提升 |
|---|---|
| **NP1** | 基础倍率 |
| **NP2** | 伤害倍率 +20% |
| **NP3** | 伤害倍率 +35% |
| **NP4** | 伤害倍率 +42.5% |
| **NP5** | 伤害倍率 +50% |

> **说明**：以上为相对提升比例，实际倍率因从者而异。


## 六、附加技能（Append Skill）

### 6.1 附加技能概述

- 每个从者拥有 3 个附加技能槽
- 附加技能不占用主动技能槽
- 需要消耗特定素材和从者硬币解锁
- 附加技能效果包括：
  - **对特定职阶攻击适性**
  - **NP 获得量提升**
  - **暴击威力提升**等

### 6.2 附加技能解锁与升级

| 阶段 | 所需素材 |
|---|---|
| **解锁** | 从者硬币 ×120 + 素材 ×X |
| **升级（Lv.1→10）** | 从者硬币 + 素材 + QP |

### 6.3 从者硬币获取方式

| 方式 | 说明 |
|---|---|
| **召唤** | 召唤同名从者时获得（★1-3：1枚，★4-5：30-50枚） |
| **羁绊提升** | 羁绊等级提升时获得 |
| **活动奖励** | 部分活动赠送从者硬币 |


## 七、羁绊提升（修正版）

### 7.1 羁绊系统概述

- 通过战斗积累羁绊值
- 羁绊等级初始上限为 **Lv.10**
- 可使用 **迦勒底梦火** 将上限提升至 **Lv.15**[reference:10]
- 每级提升需要不同数量的羁绊值

### 7.2 羁绊等级与解锁内容

| 羁绊等级 | 解锁内容 |
|---|---|
| **Lv.1** | 从者资料 1 |
| **Lv.2** | 从者资料 2 |
| **Lv.3** | 从者资料 3 |
| **Lv.4** | 从者资料 4 |
| **Lv.5** | 从者资料 5 |
| **Lv.6-9** | 额外语音、从者硬币 |
| **Lv.10** | **羁绊礼装**（专属礼装，仅限该从者装备）[reference:11][reference:12] |
| **Lv.11-15** | 额外语音、从者硬币（需使用梦火突破上限） |

### 7.3 羁绊礼装

- 羁绊等级达到 **Lv.10** 时获得[reference:13][reference:14]
- 专属礼装，仅限该从者装备
- 属性：4 星，Cost 9，HP+100 / ATK+100[reference:15][reference:16]
- 效果：通常提供该从者专属的强力加成

### 7.4 羁绊上限突破

| 道具 | 作用 |
|---|---|
| **迦勒底梦火** | 提升从者羁绊上限 1 级（最高至 Lv.15）[reference:17] |

### 7.5 羁绊上限突破后

- Lv.6-9：每级可获得从者硬币[reference:18]
- Lv.10：获得羁绊礼装
- Lv.11-15：继续获得从者硬币和额外语音


## 八、养成资源获取途径

| 资源 | 主要获取途径 |
|---|---|
| **种火（经验值）** | 种火本、活动兑换、友情点召唤 |
| **QP** | QP 本、活动兑换、主线关卡 |
| **棋子（职阶）** | 修炼场、活动兑换 |
| **技能素材** | 自由本、修炼场、活动兑换 |
| **传承结晶** | 活动奖励、主线关卡奖励 |
| **从者硬币** | 召唤同名从者、羁绊提升、活动赠送[reference:19] |
| **羁绊值** | 战斗、活动关卡 |
| **迦勒底梦火** | 活动奖励、达芬奇商店兑换 |

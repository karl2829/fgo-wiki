# FGO 游戏数据与术语手册

> 来源：Mooncell、NGA、Bilibili 等社区 | 最后更新：2026-07-23


## 一、基础游戏术语

| 术语 | 全称 / 说明 |
|---|---|
| **AP** | Action Point，体力，进行关卡所需的资源 |
| **QP** | Quantum Piece，量子，游戏内的通用货币 |
| **NP** | Noble Phantasm，宝具值，积攒到 100% 后可释放宝具[reference:0] |
| **HP** | Hit Point，生命值 |
| **ATK** | Attack，攻击力[reference:1] |
| **OC** | Over Charge，宝具过充能，与宝具效果有关，最高 5 级[reference:2] |
| **Master** | 御主，即玩家自身 |
| **Servant** | 从者/英灵，玩家可操控的角色 |
| **CE / 礼装** | Craft Essence，概念礼装，从者可装备的卡片 |
| **芙芙** | 从者 HP/ATK 强化道具（兽之足迹） |
| **圣杯** | 用于提升从者等级上限的特殊道具 |
| **梦火** | 用于将羁绊等级上限从 Lv.10 提升至 Lv.15 |
| **传承结晶** | 用于将技能从 Lv.9 提升至 Lv.10 的稀有道具 |
| **PY 码** | 玩家 ID，用于他人添加好友[reference:3] |
| **白纸化地球** | 指 "Order Call" 副本，一天最多打三次，需通关奏章序剧情开启[reference:4][reference:5] |

### 宝具等级简称

| 术语 | 说明 |
|---|---|
| **一宝/二宝/三宝/四宝/五宝** | 宝具等级 NP1 至 NP5[reference:6] |


## 二、战斗术语

| 术语 | 说明 |
|---|---|
| **周回** | 反复刷同一个关卡以获取素材或活动道具[reference:7][reference:8] |
| **打地铺** | 指日常的 33x 本，常见于量子本、剧情 free 本等[reference:9] |
| **高难** | 高难度关卡，通常指活动中的挑战本[reference:10] |
| **竞速** | 以最短回合数通关高难本的行为[reference:11] |
| **OTK** | One Turn Kill，一回合击杀 |
| **SL 大法** | Save/Load，通过重启游戏改变随机数判定（如暴击、敌方行动）[reference:12][reference:13] |
| **光炮** | 指宝具为全体攻击的从者[reference:14][reference:15] |
| **单体** | 指宝具为单体攻击的从者[reference:16][reference:17] |
| **单挑** | 仅使用一名从者进行战斗 |
| **柱子战** | 全服玩家共同讨伐固定数量敌人的特殊战斗[reference:18][reference:19][reference:20] |
| **爬塔** | 指百重塔活动，从者使用后会进入冷却[reference:21] |
| **鞭尸 / Overkill** | 攻击使敌人 HP 归零后的额外 Hit 判定[reference:22] |
| **水枪** | 指宝具伤害较低 |
| **灭世三红** | 指三张 Buster 卡组成的 Chain |
| **保鲜术** | 利用换人服将上满 Buff 的从者换到后排，待技能冷却后再换回，叠加多轮 Buff[reference:23][reference:24] |
| **冲浪** | 指连续释放宝具进行周回作战，源于早期最强连发从者水莫德雷德的宝具动画[reference:25] |
| **爆破** | 高难度副本中追求高额爆发伤害[reference:26] |
| **T / 回合** | t 为回合数的简称，常见于 3t 过本[reference:27] |
| **阴间本** | 不符合常规敌方数量配置（非 3/3/X 或 3/2/X），血量更高，不利于 NP 回收的 Free 周回本[reference:28][reference:29] |
| **阳间本** | 三面敌方配置为 "3、3、X" 或 "3、2、X" 的低血量敌人，NP 回收较为理想的 Free 周回本[reference:30][reference:31] |
| **90+ / 90++** | 副本难度系数，90 之后加 + 或 * 表示难度递增[reference:32][reference:33] |
| **XXX（数字）** | 指副本每面怪物数量，如 12 表示第一面 1 个、第二面 2 个敌人[reference:34] |


## 三、Buff 与伤害术语

| 术语 | 说明 |
|---|---|
| **Buff 稀释** | 同类 Buff 加算，种类越少实际加成越低的现象[reference:35] |
| **魔放** | 指令卡性能提升（A 类 Buff）[reference:36] |
| **黄金律** | NP 获得量提升类技能的统称[reference:37][reference:38][reference:39] |
| **直感** | 获得暴击星的技能 |
| **领导力** | 提升己方全体攻击力的技能 |
| **皇权** | 拉美西斯二世二技能「皇帝特权」的简称，效果为概率加攻加防回血[reference:40] |
| **挂 B 作成** | 梅林三技能「英雄作成」的戏称[reference:41] |
| **特攻** | 对特定属性敌人造成更高伤害[reference:42] |
| **万物特攻** | 对几乎所有敌人都有效的特攻[reference:43] |

### Buff 分类（玩家社区常用）

| 类别 | 包含内容 | 说明 |
|---|---|---|
| **A 类** | 魔放（指令卡性能） | 同类加算，易稀释[reference:44] |
| **B 类** | 加攻 / 降防 | 同类加算，易稀释[reference:45] |
| **C 类** | 宝具威力 / 暴击威力 / 特攻 | 同类加算，非常容易稀释[reference:46] |
| **D 类** | 宝具特攻 | 唯一不会被稀释的 Buff 类型[reference:47] |
| **E 类** | 固定增伤 | 独立乘区[reference:48] |

## 六、抽卡与卡池术语

| 术语 | 说明 |
|---|---|
| **UP / Pick Up** | 卡池中特定从者/礼装的出现概率提升[reference:78] |
| **歪了** | 在 UP 池中抽到了非 UP 的五星从者 |
| **一单** | 指一次最大额度的氪金（约 518 元 = 167 个圣晶石）[reference:79] |
| **保底 / 天井** | 330 抽必定获得当期 UP 五星从者（每个卡池仅一次）[reference:80] |

| **呼符** | 可用于单抽的道具，又称“船票” |
| **海景房** | 指极难获得的限定从者[reference:82] |
| **欧证** | 仅能在友情池中获得的低星从者[reference:83] |
| **碎石** | 使用圣晶石回复 AP 继续刷本[reference:84] |
| **千里眼** | 利用国服与日服约一年的进度差，提前规划抽卡[reference:85][reference:86][reference:87] |
| **千石一宝** | 指花费 1000 个圣晶石才抽到 1 个当期 UP 五星的悲惨经历[reference:88] |
| **晒卡** | 抽卡后向他人炫耀的行为，晒卡者常被称为“海豹”[reference:89] |

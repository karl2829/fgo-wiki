# FGO 战斗机制：MISS / GUARD / 暴击

> 来源：atlasacademy/fgo-docs + Mooncell 游戏数据基础 | 最后更新：2026-07-23


## 一、MISS 判定机制

### 1.1 MISS 的定义

- 攻击未能命中目标
- 伤害为 **0**
- 不产生任何效果（不触发伤害、不产生 NP、不产生暴击星等）

### 1.2 MISS 的触发条件

| 触发条件 | 说明 |
|---|---|
| **敌方回避状态** | 敌方持有「回避」状态时，攻击有概率 MISS |
| **敌方无敌状态** | 敌方持有「无敌」状态时，攻击 MISS（除非持有「无敌贯通」） |
| **命中率下降** | 我方命中率下降至 0% 或以下时，攻击 MISS |
| **敌方特殊技能** | 部分敌方单位拥有强制 MISS 的特殊技能 |

### 1.3 MISS 与回避/无敌的区别

| 状态 | 效果 | MISS判定 |
|---|---|---|
| **回避** | 对持有者的攻击有概率 MISS | 概率性（受命中率影响） |
| **无敌** | 对持有者的攻击必定 MISS | 必定（除非持有无敌贯通） |
| **即死** | 不经过伤害计算，直接死亡 | 独立判定（不视为 MISS） |

### 1.4 MISS 的影响

- 不产生任何伤害
- 不产生 NP
- 不产生暴击星
- 不触发任何「被攻击时」效果（如「受击 NP 增加」等）


## 二、GUARD 判定机制

### 2.1 GUARD 的定义

- 攻击命中但伤害被大幅削减的状态
- 伤害倍率降至 **0.1 倍**（即 10% 伤害）
- 仍会产生 NP 和暴击星（以原伤害计算）

### 2.2 GUARD 的触发条件

| 触发条件 | 说明 |
|---|---|
| **防御技能** | 持有「防御力提升」或「伤害减免」类效果 |
| **职阶克制** | 被克制时伤害降低至 0.5 倍（不是 GUARD，但效果类似） |
| **特殊状态** | 部分敌人持有强制 GUARD 的状态 |

### 2.3 GUARD 的视觉标识

- 游戏内显示为 **GUARD** 字样（而非 MISS）
- 伤害显示为白色小字（表示伤害减少）

### 2.4 GUARD 与伤害减免的区别

| 概念 | 说明 |
|---|---|
| **GUARD** | 伤害 × 0.1 倍（固定倍率） |
| **伤害减免** | 固定值减免（如 500 HP 减免） |
| **防御力** | 百分比降低伤害（如防御提升 30%） |


## 三、暴击判定机制

### 3.1 暴击的定义

- 伤害倍率 × **2.0**（固定常数为 2）
- 暴击星消耗量取决于各从者分配到的星星数量

### 3.2 暴击概率计算
暴击概率 =
min(每颗星星的暴击率 × 分配到该从者的星星数, 100%)



- 每颗星星的暴击率 = **10%**
- 星星分配基于从者的暴击权重（`criticalWeight`）
- 暴击概率上限为 **100%**

### 3.3 暴击星分配机制
分配到某从者的星星数 =
(该从者的暴击权重 / 所有从者暴击权重总和) × 当前持有星星数



### 3.4 暴击权重的典型值

| 职阶 | 典型暴击权重 |
|---|---|
| **Rider** | 200~205（最高） |
| **Archer** | 150~155 |
| **Assassin** | 100~105 |
| **Saber** | 100~105 |
| **Lancer** | 90~95 |
| **Caster** | 50~55（最低） |

### 3.5 影响暴击概率的因素

| 因素 | 说明 |
|---|---|
| **暴击星数量** | 星星越多，暴击概率越高 |
| **暴击权重** | 权重高的从者更容易分配到星星 |
| **暴击威力** | 提升暴击时的伤害（`critDamageMod`） |
| **暴击率 Buff** | 部分从者技能可提升暴击率（如「直感」） |

### 3.6 暴击与 MISS/GUARD 的交互

- MISS 时：不产生暴击（攻击未命中）
- GUARD 时：暴击伤害仍为 ×2，但 GUARD 伤害 ×0.1 倍，最终伤害为原始伤害的 0.2 倍（2×0.1）


## 四、敌方暴击 MISS 判定（Critical Miss）

### 4.1 Critical Miss 的定义

- 敌方暴击攻击时，有一定概率 MISS
- 适用于敌方的暴击攻击

### 4.2 Critical Miss 的触发条件

| 触发条件 | 说明 |
|---|---|
| **我方回避状态** | 敌方暴击攻击被回避时触发 Critical Miss |
| **我方无敌状态** | 敌方暴击攻击被无敌状态抵消时触发 Critical Miss |
| **命中率下降** | 我方降低敌方命中率时 |

### 4.3 Critical Miss 的效果

- 敌方暴击攻击完全 MISS
- 不产生任何伤害或效果


## 五、特殊机制

### 5.1 暴击星上限

- 每回合最多持有 **50 颗**暴击星
- 超过 50 颗的部分被丢弃

### 5.2 暴击星与攻击顺序

- 暴击星分配在**攻击开始前**完成
- 每张指令卡独立计算暴击概率（基于该从者分配到的星星数）

### 5.3 暴击与 Overkill

- 暴击可提高伤害，更容易触发 Overkill
- Overkill 可增加 NP 获得量和暴击星获得量

### 5.4 回避、无敌与 MISS 的关系

| 状态 | MISS判定 | 是否消耗 | 备注 |
|---|---|---|---|
| **回避** | 概率性 | 不消耗（除非攻击命中，否则不消耗） | 可被「必中」和「无敌贯通」无视 |
| **无敌** | 必定 | 不消耗（除非攻击命中，否则不消耗） | 可被「无敌贯通」无视 |
| **GUARD** | 不 MISS | — | 伤害降低至 0.1 倍 |


## 六、常量汇总

| 常量 | 值 | 说明 |
|---|---|---|
| 暴击伤害补正常数 | **2.0** | 暴击时伤害 ×2 |
| GUARD 伤害倍率 | **0.1** | GUARD 时伤害 ×0.1 |
| 每颗星星暴击率 | **10%** | 1 颗星 = 10% 暴击概率 |
| 暴击星上限 | **50** | 每回合最多 50 颗 |


## 七、计算示例

### 7.1 暴击概率计算示例

假设当前有 **30 颗暴击星**，场上从者暴击权重分别为：
- 从者A（Saber）：权重 100
- 从者B（Archer）：权重 150
- 从者C（Rider）：权重 205


总权重 = 100 + 150 + 205 = 455

从者A分配到的星星数 = 30 × (100/455) ≈ 6.59 → 6-7 颗
从者B分配到的星星数 = 30 × (150/455) ≈ 9.89 → 9-10 颗
从者C分配到的星星数 = 30 × (205/455) ≈ 13.52 → 13-14 颗

从者A暴击概率 = min(6 × 10%, 100%) = 60%
从者B暴击概率 = min(9 × 10%, 100%) = 90%
从者C暴击概率 = min(13 × 10%, 100%) = 100%


### 7.2 GUARD 伤害计算示例

假设原始伤害为 **1000**：
- GUARD 时：1000 × 0.1 = **100**

### 7.3 暴击 + GUARD 伤害计算示例

假设原始伤害为 **1000**：
- 暴击 + GUARD：1000 × 2.0 × 0.1 = **200**

# FGO NP 获得量公式

> 来源：atlasacademy/fgo-docs + Mooncell 游戏数据基础 | 最后更新：2026-07-23


## 第一部分：NP 获得量计算

### 一、NP 获得量计算公式

#### 1.1 攻击时 NP 获得（指令卡攻击）


NP获得量 =
floor(
(
(指令卡NP获得率 × 首位加成)

(敌补正 × (1 + npChargeRateMod))

自身NP获得量提升
)
× 指令卡补正
× 位置补正
× (1 + Overkill补正)
× 各Hit百分比
)

**简化理解版**：

NP获得 ≈ 基础NP率 × 各种补正 × Hit数



#### 1.2 被攻击时 NP 获得

NP获得量 = 被攻击NP率 × (1 + npChargeRateMod) × 被攻击Hit数


#### 1.3 宝具 NP 获得

- 宝具的 NP 获得量由宝具本身的 `npGain` 字段决定
- 宝具 NP 不受指令卡补正和位置补正影响
- 受 npChargeRateMod 影响

### 二、各项参数详细说明

#### 2.1 指令卡NP获得率

- 从者基础属性，每个从者不同
- 通常 Arts 卡最高，Quick 卡次之，Buster 卡最低
- 可在从者数据中查看（`.npGain.attack` 和 `.npGain.defense`）

#### 2.2 首位加成（First Card Bonus）

| 首卡类型 | NP加成 | 说明 |
|---|---|---|
| **Arts** | **+100%** | 后续所有卡的 NP 获得量 ×2 |
| **Buster** | 0% | 无 NP 加成 |
| **Quick** | 0% | 无 NP 加成 |

- 仅当首卡是 Arts 时，后续卡片的 NP 获得量 ×2
- 这是 NP 获取中最关键的加成之一

#### 2.3 敌补正（enemyServerMod）

- 敌方单位特有的 NP 获得补正
- 不同敌人的补正不同（常见值为 1.0）
- 来源：atlasacademy/fgo-docs 中的 `enemyServerMod` 常量

#### 2.4 npChargeRateMod（NP 获得量 Buff）

- 对应「NP获得量提升/下降」类效果
- 上下限：**0% ~ 500%**
- 同名 Buff 叠加（加算）
- 来源：技能、礼装、宝具等

#### 2.5 指令卡补正（Card NP Mod）

| 指令卡类型 | NP补正 |
|---|---|
| **Arts** | **3.0** |
| **Quick** | 1.0 |
| **Buster** | 0.0 |
| **Extra** | 1.0 |

- Arts 卡是 NP 获取的主要来源（3倍补正）
- Buster 卡本身不产生 NP（即 NP 获得量为 0）

#### 2.6 位置补正（Position Mod）

| 卡片位置 | NP补正 |
|---|---|
| **第1位** | **1.0** |
| **第2位** | **1.5** |
| **第3位** | **2.0** |

- 位置越靠后，NP 获得量越高
- 第3位是第1位的 2 倍

#### 2.7 Overkill 补正

- 当攻击使敌方 HP 归零时触发
- 补正值：**1.0**（即无额外补正，仅正常计算）
- 实际上 Overkill 本身不直接增加 NP，而是通过增加 Hit 数来间接增加 NP

#### 2.8 被攻击NP率

- 从者被攻击时的基础 NP 获得率
- 可在从者数据中查看（`.npGain.defense`）
- 不同从者不同，通常比攻击 NP 率低

### 三、NP 获得 Buff 上限

| 项目 | 上限值 |
|---|---|
| npChargeRateMod（NP获得量） | 500% |
| 指令卡 NP 补正 | 无固定上限（由卡片类型决定） |
| 位置补正 | 1.0 ~ 2.0 |
| Arts Chain 加成 | 额外 +20% NP（固定） |

### 四、特殊机制

#### 4.1 Arts Chain 额外 NP

- 一回合内使用 3 张 Arts 卡时触发
- 额外获得 **20% NP**（固定值）
- 该 NP 由全体从者获得

#### 4.2 鞭尸（Overkill）对 NP 的影响

- 当攻击使敌方 HP 归零时，该 Hit 的 NP 获得量**不减少**
- 实际上 Overkill 通过增加有效 Hit 数，间接提高 NP 获得量

#### 4.3 NP 获得量上限

- 单次攻击（单个 Hit）的 NP 获得量无明确上限
- 但受 `npChargeRateMod` 上限 500% 的限制

### 五、计算示例

**示例：阿尔托莉雅使用 Arts 卡攻击（第3位）**

- 基础 NP 获得率：0.86%（假设值，实际以从者数据为准）
- 首卡：Arts（首位加成 +100%）
- 指令卡补正：Arts = 3.0
- 位置补正：第3位 = 2.0
- 无其他 Buff
NP获得量 =0.86 × (1 + 1.0) × 3.0 × 2.0
= 0.86 × 2.0 × 3.0 × 2.0
= 10.32%



即攻击一次可获得约 10.32% NP。

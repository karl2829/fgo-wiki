# FGO 伤害计算公式

> 来源：atlasacademy/fgo-docs + Mooncell 游戏数据基础 | 最后更新：2026-07-23


## 一、完整伤害公式

伤害 =
floor(
(
(servantAtk × 0.23)
× (
1 + atkMod + defMod + 特攻状态 + 宝具特攻 + 特殊耐性 - 特殊威力 - 特殊耐性(防御)

npDamageMod + critDamageMod
)
× cardMod
× powerMod
× 职阶克制
× 阵营克制
× randomModifier
× (1 + 首位加成)

伤害附加 - 伤害减免
)
× 1.0 (如有 Overkill)
)
/ 100



**简化理解版**：
伤害 ≈ (ATK × 0.23) × 各乘区补正 × 随机数


其中各项补正为**乘算**关系，最终结果向下取整。


## 二、各项乘区详细说明

### 1. servantAtk（攻击力）

- 使用从者**实际攻击力**（含芙芙、礼装、技能等所有加成后的最终值）
- 敌方 ATK 计算方式与玩家方相同（不含染色和礼装加成）

### 2. 常数系数 0.23

- 伤害公式中的固定系数
- 来源：游戏底层设定的伤害换算系数

### 3. atkMod（攻击力 Buff）

- 对应游戏内「攻击力提升/下降」
- 上下限：**0% ~ 500%**
- 同名 Buff 叠加（加算）
- 来源：技能、宝具、礼装等

### 4. defMod（防御力 Buff）

- 对应「防御力提升/下降」
- 下限：无限制（可低于0%）
- 上限：无限制
- 同名 Buff 叠加（加算）

### 5. 特攻状态（特攻状态）

- 对应「对[特性]特攻状态」
- 常见于从者技能（如“对龙特攻”）
- 与宝具特攻、特殊威力等**加算**

### 6. 宝具特攻（宝具特攻）

- 宝具自带的特攻效果（如“对[魔性]特攻”）
- 与特攻状态、特殊耐性等**加算**

### 7. 特殊耐性（特殊耐性）

- 对应「对[特性]伤害耐性」
- 与特攻状态、宝具特攻等**加算**

### 8. 特殊威力（特殊威力）

- 对应「特殊威力提升」类效果
- 最大值：**1000%**
- 与特攻状态等**加算**

### 9. npDamageMod（宝具威力 Buff）

- 对应「宝具威力提升/下降」
- 上下限：**0% ~ 500%**
- 只影响宝具伤害
- 同名 Buff 叠加（加算）

### 10. critDamageMod（暴击威力 Buff）

- 对应「暴击威力提升/下降」
- 上下限：**0% ~ 500%**
- 只影响暴击时的伤害

### 11. cardMod（指令卡性能 Buff）

- 对应「Buster/Arts/Quick 卡性能提升/下降」
- 上下限：**0% ~ 500%**
- 只影响对应色卡的伤害

### 12. powerMod（威力提升）

- 对应「威力提升/下降」
- 上下限：**0% ~ 1000%**
- 同名 Buff 叠加（加算）
- 包含「对[特性]特攻」的同类效果

### 13. 职阶克制（Class Affinity）

- **克制**：2.0 倍
- **被克制**：0.5 倍
- **无克制**：1.0 倍
- 具体克制关系参见 `class_affinity.md`

### 14. 阵营克制（Attribute Affinity）

- **克制**：1.1 倍
- **被克制**：0.9 倍
- **无克制**：1.0 倍
- 具体克制关系参见 `class_affinity.md`

### 15. randomModifier（随机数）

- 范围：**[900, 1100)**（含900，不含1100）
- 即随机取值 900, 901, ..., 1099（共200个整数）
- 最终除以 1000，即 0.9 ~ 1.099 之间的随机系数

#### ⚠️ 特殊从者的随机数

- **阿拉什（Arash）**：Stella 宝具的 Over Charge 效果使用独立的随机数范围（与普通规则不同）
- **陈宫（Chen Gong）**：宝具的 Over Charge 效果同样使用独立的随机数

### 16. 首位加成（First Card Bonus）

- **红卡**作为首卡时：后续卡片伤害 × **1.5**（对敌方也生效）
- **蓝卡/绿卡**作为首卡时：无伤害加成（仅影响NP和星星）
- 仅当首卡是红卡时生效

### 17. 伤害附加（dmgPlusAdd）

- 对应「伤害附加」类效果（如“伤害+500”）
- 固定值加算，不受其他 Buff 影响
- 常见于一些礼装或技能效果

### 18. 伤害减免（dmgCutAdd）

- 对应「伤害减免」类效果（如“伤害减免500”）
- 固定值减算，不受其他 Buff 影响

### 19. Overkill 加成

- 当攻击使敌方 HP 归零（Overkill）时
- 伤害倍率 × **1.0**（即无额外加成，仅正常计算）


## 三、关键上限汇总

| 项目 | 上限值 |
|---|---|
| atkMod（攻击力 Buff） | 500% |
| defMod（防御力 Buff） | 无固定上限 |
| cardMod（指令卡性能） | 500% |
| powerMod（威力提升） | 1000% |
| critDamageMod（暴击威力） | 500% |
| npDamageMod（宝具威力） | 500% |
| 特攻状态 + 宝具特攻 + 特殊耐性 + 特殊威力 | 无固定上限（加算后参与计算） |


## 四、特殊机制

### 1. Buster Chain 额外伤害

- 当一回合内使用 3 张 Buster 卡时
- 在正常伤害之外，额外附加 **0.2 × servantAtk** 的伤害
- 这个额外伤害**不受任何补正影响**（直接加到最终结果前）

### 2. 敌方行动 AI 与伤害

- 敌方的 ATK 计算方式与玩家方相同（即 `enemyAtk × 0.23 × 其他补正`）
- 敌方不受指令卡染色或礼装加成影响

### 3. 伤害公式执行顺序

1. 基础攻击力 × 0.23
2. 乘以所有乘区补正（atkMod 系、cardMod、powerMod、克制、随机数等）
3. 加上固定值（dmgPlusAdd）
4. 减去固定值（dmgCutAdd）
5. 最后除以 100（因为所有百分比值都扩大了100倍存储）

### 4. 倍率表示法

游戏内所有百分比数值在底层存储时是整数形式（如 30% 存储为 30），计算时最后统一除以 100。


## 五、计算示例

**示例：阿尔托莉雅（Saber）攻击敌人（Lancer）**

- ATK：12000
- atkMod：20%（攻击力提升）
- cardMod：30%（Buster 性能提升）
- 职阶克制：Saber → Lancer = 2.0 倍
- 阵营克制：天 → 人 = 1.1 倍
- randomModifier：1000（即 1.0）
- 无其他 Buff


伤害 =
floor(
(
(12000 × 0.23)
× (1 + 0.20)
× (1 + 0.30)
× 2.0
× 1.1
× 1.0
)
/ 100
)
= floor( (2760 × 1.2 × 1.3 × 2.0 × 1.1) / 100 )
= floor( (2760 × 3.432) / 100 )
= floor( 9472.32 / 100 )
= 94


实际伤害为 94（未考虑随机数微调）。

> **注意**：实际游戏中的随机数会使伤害在 0.9 ~ 1.099 倍之间浮动。


## 六、补充说明

- 伤害计算中所有百分比值（如 30%）在底层存储为整数 30，最终统一除以 100
- 各类 Buff 的上下限执行顺序：先计算 `base + plus - minus`，再应用 normal/lower/upper 限制
- 同类 Buff 之间为**加算**，不同类为**乘算**
- 伤害最终结果向下取整（`floor`）

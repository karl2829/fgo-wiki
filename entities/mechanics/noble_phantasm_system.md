# FGO 宝具系统

> 来源：atlasacademy/fgo-docs + Mooncell + FGO Wiki | 最后更新：2026-07-23


## 一、宝具基础

### 1.1 什么是宝具？

宝具是从者持有的必杀技，通过积攒 NP（宝具值）来发动。每个从者拥有 1 个宝具（部分从者拥有 2 个），宝具的效果和倍率由从者自身的设定决定。

### 1.2 宝具的分类

| 分类方式 | 类型 | 说明 |
|---|---|---|
| **攻击范围** | **单体宝具** | 对敌方单体造成伤害 |
| | **全体宝具** | 对敌方全体造成伤害 |
| | **辅助宝具** | 不造成伤害，提供 Buff/治疗/其他效果 |
| **卡色** | **Buster 宝具** | 红色，高伤害 |
| | **Arts 宝具** | 蓝色，中伤害 + NP 获得 |
| | **Quick 宝具** | 绿色，中伤害 + 暴击星获得 |
| **类型（游戏内）** | **对人宝具** | 对单个敌人 |
| | **对军宝具** | 对群体敌人 |
| | **对城宝具** | 对要塞/城池 |
| | **结界宝具** | 防御/辅助型 |


## 二、宝具等级与伤害倍率

### 2.1 宝具等级（NP Level）

- 宝具等级通过**宝具强化**（喂同名从者）提升
- 初始为 **宝具 1（NP1）**
- 最高为 **宝具 5（NP5）**
- 宝具等级影响**宝具伤害倍率**，不影响 Over Charge 效果

### 2.2 宝具伤害倍率（以 5★ 从者为例）

| 宝具类型 | NP1 | NP2 | NP3 | NP4 | NP5 |
|---|---|---|---|---|---|
| **单体 Buster** | 600% | 800% | 900% | 950% | 1000% |
| **单体 Arts** | 900% | 1200% | 1350% | 1425% | 1500% |
| **单体 Quick** | 1200% | 1600% | 1800% | 1900% | 2000% |
| **全体 Buster** | 300% | 400% | 450% | 475% | 500% |
| **全体 Arts** | 450% | 600% | 675% | 712.5% | 750% |
| **全体 Quick** | 600% | 800% | 900% | 950% | 1000% |

> **说明**：以上为典型值，实际数值因从者而异，请以游戏内数据为准。

### 2.3 辅助宝具的等级影响

- 辅助宝具通常**不受宝具等级影响**（或影响较小）
- 其效果更多受 Over Charge 影响

### 2.4 宝具伤害在伤害公式中的位置

宝具伤害的计算与指令卡伤害相同，但有以下特点：

- **不享受位置补正**（宝具只有 1 次攻击）
- **享受首位加成**（受首卡加成影响）
- **受 NP 相关 Buff 影响**（宝具威力、NP 获得量等）
- **不受指令卡位置补正影响**


## 三、Over Charge 系统

### 3.1 Over Charge 的定义

Over Charge（OC）是指宝具发动时，NP 超过 100% 的部分带来的额外效果提升。

| 状态 | NP 值 | Over Charge 等级 |
|---|---|---|
| **NP1** | 100% ~ 199% | OC1 |
| **NP2** | 200% ~ 299% | OC2 |
| **NP3** | 300% ~ 399% | OC3 |
| **NP4** | 400% ~ 499% | OC4 |
| **NP5** | 500% | OC5 |

### 3.2 Over Charge 与宝具等级的区别

| 对比项 | 宝具等级（NP Level） | Over Charge（OC） |
|---|---|---|
| **决定方式** | 宝具强化次数（喂同名从者） | 发动时的 NP 蓄力值 |
| **影响范围** | 宝具伤害倍率 | 宝具的额外效果 |
| **提升方式** | 长期养成 | 战斗中的战术选择 |
| **上限** | 宝具 5 | OC5（NP 500%） |

### 3.3 Over Charge 效果分类

| 效果类型 | 说明 | 示例 |
|---|---|---|
| **伤害倍率提升** | Over Charge 提高宝具伤害倍率 | 阿拉什（Stella） |
| **额外效果提升** | Over Charge 提高附加效果的数值 | 梅林（英雄作成） |
| **特殊效果解锁** | Over Charge 解锁额外效果 | 奥伯龙（于彼方点缀的梦之童话） |

### 3.4 Over Charge 提升方式

| 方式 | 说明 |
|---|---|
| **自身蓄力** | 通过指令卡、技能、宝具等积攒 NP 超过 100% |
| **NP 填充技能** | 技能直接填充 NP（如孔明「鉴识眼」+50%） |
| **他人宝具** | 某些从者的宝具可增加队友的 NP |
| **Over Charge 加成** | 部分礼装/技能可提升 Over Charge 等级 |


## 四、宝具封印与封印解除

### 4.1 宝具封印

- **宝具封印**状态：从者无法使用宝具（指令卡栏中的宝具卡被锁定）
- 常见来源：敌方技能、敌方宝具、部分从者技能
- 持续时间：通常为 1-3 回合

### 4.2 封印解除方式

| 方式 | 说明 |
|---|---|
| **自然解除** | 等待封印状态回合数结束 |
| **弱体解除技能** | 使用「弱体解除」类技能（如玛修「盾牌」） |
| **宝具封印解除技能** | 部分从者拥有专门解除宝具封印的技能 |
| **死亡/替换** | 从者死亡或替换后状态清除 |

### 4.3 宝具封印与 NP

- 宝具封印状态下，NP 仍可正常获得
- 封印解除后，NP 保留
- 封印不消耗 NP


## 五、宝具强化

### 5.1 宝具强化方式

| 强化方式 | 说明 | 效果 |
|---|---|---|
| **宝具强化（喂同名）** | 消耗同名从者进行宝具强化 | 提升宝具等级（NP1→NP2...） |
| **宝具强化本（技能）** | 从者的强化任务（幕间物语） | 提升宝具伤害倍率或增加效果 |

### 5.2 宝具强化素材

- **宝具强化（喂同名）**：同名从者（1 个 = NP+1）
- **宝具强化本**：特定关卡通关即可，无需额外素材

### 5.3 宝具强化倍率表

| 宝具等级 | 伤害倍率（单体） | 伤害倍率（全体） |
|---|---|---|
| **NP1** | 100% | 100% |
| **NP2** | 120% | 120% |
| **NP3** | 135% | 135% |
| **NP4** | 142.5% | 142.5% |
| **NP5** | 150% | 150% |

> **说明**：以上为相对提升比例。实际伤害倍率以各从者数据为准。


## 六、宝具与指令卡

### 6.1 宝具与首位加成

- 宝具卡**不参与指令卡抽取**，独立位于指令卡栏最右侧
- 宝具卡**不享受位置补正**（位置固定）
- 宝具卡**受首位加成影响**：
  - 首卡 Buster：宝具伤害 ×1.5
  - 首卡 Arts：宝具 NP 获得 ×2（仅对宝具的 NP 获得部分生效）
  - 首卡 Quick：宝具暴击星获得率 +20%（仅对宝具的暴击星获得部分生效）

### 6.2 宝具与 Chain

- 宝具卡**不触发同色 Chain**（不参与 Buster/Arts/Quick Chain 判定）
- 宝具卡**不触发 Brave Chain**
- 宝具卡**不消耗指令卡**（不占用指令卡位置）

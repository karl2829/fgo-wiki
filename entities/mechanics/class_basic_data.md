## 二、副属性（天/地/人/星/兽）克制

副属性克制倍率为 **1.1 / 0.9**，与职阶克制乘算叠加。

| 攻\防 | 天 | 地 | 人 | 星 | 兽 |
| --- | --- | --- | --- | --- | --- |
| 天 |  | 1.1 | 0.9 |  |  |
| 地 | 0.9 |  | 1.1 |  |  |
| 人 | 1.1 | 0.9 |  |  |  |
| 星 |  |  |  |  | 1.1 |
| 兽 |  |  |  | 1.1 |  |

### 副属性含义

- **天**：神灵降格而成的英灵，或神之子、传承的具现化
- **地**：当地传说中的英雄，妖精、魔兽等
- **人**：实际存在过的英雄伟人
- **星**：不属于天、地、人的例外，人类的希望（不受天地人克制）
- **兽**：与星相克

## 三、职阶克制

完整职阶克制矩阵见 [职阶与阵营克制](./class_affinity.md)。要点：

- 常规七骑：剑克枪、枪克弓、弓克剑；骑克术、术克杀、杀克骑（2.0 / 0.5）
- Berserker：攻击多数职阶 1.5 倍，被常规职阶攻击 2 倍
- Ruler：攻击常规职阶 1.1 倍，被常规职阶攻击 0.5 倍，被 Avenger 克制
- Alterego：克 Foreigner 及下三骑（Rider/Caster/Assassin），被 Pretender 克制
- MoonCancer 克 Foreigner；Pretender 克 Alterego
- Shielder：无任何克制关系

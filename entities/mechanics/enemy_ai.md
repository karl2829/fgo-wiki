# FGO 敌方AI与行动模式

> 来源：atlasacademy/fgo-docs + Mooncell + FGO Wiki | 最后更新：2026-07-23


## 一、敌方行动的核心机制

敌方行动由三个核心要素决定：**行动次数、行动优先级、气槽系统**。

### 1.1 行动次数

- **上限规则**：与玩家一回合可选择3张指令卡类似，敌方每回合最多行动3次
- **职阶差异**：不同职阶的敌人行动次数不同
  - 术阶、狂阶敌人通常每回合行动2次
  - 其他职阶通常每回合行动3次
- **稀有度差异**：
  - 金色敌人：通常3动
  - QP本、狗粮本的门类敌人：通常1动
  - 银/铜小怪：通常1-2动
- **关键规则**：敌方使用技能会**消耗一次行动次数**

### 1.2 行动优先级

当回合内多个敌人都有行动机会时，按行动优先级决定出手顺序。

| 属性 | 说明 |
|---|---|
| **判定方式** | 行动优先级数值越高的敌人，行动顺序越靠前 |
| **实战价值** | 可预判谁将先释放宝具，提前做好应对准备 |
| **行动打断** | 若高优先级敌人在行动中击杀了持有嘲讽状态的单位，后续敌人的攻击可能被**直接终止** |

### 1.3 气槽系统

敌人的宝具系统独立于玩家的NP条，使用“气槽”机制。

| 属性 | 说明 |
|---|---|
| **充能规则** | 气槽通常有2-5格，每回合自动前进1格 |
| **宝具释放** | 气槽满格后，敌人将在下一次行动时释放宝具 |
| **职阶影响** | 弓阶、杀阶、丑阶、月癌阶的敌人气槽最短，释放宝具最快 |
| **技能充能** | 敌人使用技能通常可立即增加1格气槽，部分强力技能可增加2格 |
| **玩家应对** | 灭气技能（减少气槽）、宝具封印（阻止宝具释放并阻止气槽增长） |

### 1.4 职阶与气槽格数

| 职阶 | 气槽格数 | 宝具释放速度 |
|---|---|---|
| **Saber / Lancer / Rider / Caster / Berserker / Ruler / Avenger / Alterego / Foreigner / Pretender** | 3-4格 | 中等 |
| **Archer / Assassin / MoonCancer** | 2-3格 | 最快 |
| **特殊敌人（如高难Boss）** | 3-5格 | 视具体设定 |

> **说明**：以上为典型值，具体数值因敌人而异。


## 二、高级AI行为模式

### 2.1 特殊攻击偏好

部分Boss（尤其是高难本）会设定特殊的攻击目标偏好：

| 偏好类型 | 说明 | 示例 |
|---|---|---|
| **职阶偏好** | 优先攻击特定职阶 | “优先攻击术阶从者” |
| **性别偏好** | 优先攻击特定性别 | “优先攻击男性从者” |
| **状态偏好** | 优先攻击持有特定状态的从者 | “优先攻击持有攻击Buff的从者” |
| **位置偏好** | 优先攻击特定站位 | “优先攻击从者1号位” |

### 2.2 嘲讽与攻击逻辑

- 持有**嘲讽状态**的单位会强制成为攻击目标
- 若嘲讽单位被击杀，**后续敌人的攻击可能被跳过**
- 部分敌人拥有“战续触发后跳过下一动”的特殊规则

### 2.3 Break血条与行动变化

部分Boss拥有Break血条系统（即多管血条）：

| Break阶段 | 可能的行为变化 |
|---|---|
| **Break 1** | 获得新的固定状态、变更攻击模式 |
| **Break 2** | 充能速度加快、获得额外行动次数 |
| **Break 3** | 解锁强力技能、宝具升级 |

### 2.4 特殊行动脚本

部分Boss拥有独特的战斗脚本：

| 脚本类型 | 说明 |
|---|---|
| **开局技能** | 战斗开始时自动释放特定技能（如“献祭小兵获得Buff”） |
| **回合触发** | 特定回合（如第3回合、第5回合）强制释放技能 |
| **条件触发** | 满足特定条件时触发（如“HP低于50%时获得强化”） |
| **Break触发** | 血条被击破时触发特殊效果 |


## 三、气槽系统的交互

### 3.1 气槽对玩家策略的影响

| 策略 | 作用 |
|---|---|
| **灭气技能** | 减少敌人气槽，延缓宝具释放 |
| **宝具封印** | 阻止宝具释放，同时阻止气槽增长 |
| **回避/无敌** | 在敌人宝具回合规避伤害 |
| **嘲讽+无敌** | 集中承受宝具伤害 |

### 3.2 常见灭气技能

| 从者 | 技能 | 效果 |
|---|---|---|
| **孔明** | 军师忠言 | 减少敌方1格气槽 |
| **玉藻前** | 咒层·黑天洞 | 减少敌方1格气槽 |
| **贞德** | 启示 | 减少敌方1格气槽 |
| **梅林** | 梦幻的领袖魅力 | 减少敌方1格气槽（需强化本） |

### 3.3 宝具封印技能

| 从者 | 技能 | 效果 |
|---|---|---|
| **王哈桑** | 晚钟 | 宝具封印（1回合） |
| **BB** | 黄金的戒指 | 宝具封印（1回合） |
| **杀生院祈荒** | 反·救世主 | 宝具封印（1回合） |

## 五、实战应用建议

1. **高难本前**：优先了解敌方气槽长度和特殊攻击偏好
2. **灭气角色**：孔明、玉藻前、贞德等是应对宝具的优选
3. **嘲讽策略**：善用嘲讽+无敌/回避的组合，规避单体宝具
4. **Break预判**：提前准备应对Break后的变化（如解除Buff）
5. **行动打断**：利用击杀嘲讽单位打断敌方后续行动


## 六、关键常量汇总

| 常量 | 值 | 说明 |
|---|---|---|
| 每回合最大行动次数 | 3 | 敌方每回合最多行动3次 |
| 气槽自动充能 | 1格/回合 | 每回合自动前进1格 |
| 技能充能 | +1格 | 通常技能增加1格气槽 |
| 强力技能充能 | +2格 | 部分强力技能增加2格气槽 |
| 宝具封印 | 阻止气槽增长 | 宝具封印状态期间气槽不增长 |
| 嘲讽击杀 | 打断后续行动 | 嘲讽单位被击杀后后续攻击可能被跳过 |

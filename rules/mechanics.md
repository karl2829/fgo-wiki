# 游戏机制文档生成规则

## 目录结构
```
entities/mechanics/
├── index.md                    # 导航索引
├── game_terms.md               # 术语/黑话/昵称
├── damage_formula.md           # 伤害计算公式
├── np_gain_formula.md          # NP 获得公式
├── star_gain_formula.md        # 暴击星获取公式
├── buff_system.md              # Buff 分类与计算
├── command_card.md             # 指令卡系统
├── battle_mechanics.md         # MISS/GUARD/暴击机制
├── noble_phantasm_system.md    # 宝具系统
├── servant_ascension_skill.md  # 从者养成系统
├── enemy_ai.md                 # 敌方 AI 与行动模式
├── class_affinity.md           # 职阶/阵营克制
└── constants.md                # 游戏常数汇总
```

## 通用格式要求
- 所有数学公式用代码块或 LaTeX 语法
- 关键参数用表格列出（参数名、数值、说明）
- 示例计算必须有完整步骤
- 版本/更新日期标注在文件头部

## 各文件内容规范

### 1. index.md
- 所有文档的导航目录
- 每项：文件名 | 标题 | 一句话描述
- 按类别分组：战斗计算、系统机制、养成、敌方、常数

### 2. game_terms.md
- 分类：战斗术语、养成术语、社区黑话、从者昵称、活动/道具术语
- 格式：`术语` - 解释（来源/语境）
- 包含英文对照（如 NP = Noble Phantasm）

### 3. damage_formula.md
- 基础伤害公式（完整展开）
- 各乘区：基础、职阶、属性、宝具、Buff、暴击、特攻、卡性能、首位、Chain
- 随机因子（0.9~1.1）
- 伤害上限（单次/单卡/总计）
- 示例：Lv.90 Saber 打 Lv.90 Lancer 的完整计算

### 4. np_gain_formula.md
- NP 获得来源：受击、攻击、Arts 卡、技能、宝具、被动
- 计算公式（含首位、卡性能、NP 获得量加成、职阶系数）
- NP 上限（200%/300%/500%）
- 示例

### 5. star_gain_formula.md
- 暴击星获取来源：Quick 卡、暴击、技能、宝具、被动
- 计算公式（含首位、星获取率加成、职阶系数）
- 星分配规则（权重、概率）
- 示例

### 6. buff_system.md
- Buff 分类：攻击/防御/NP/星/功能/特殊
- 叠加规则：同类乘法/加法、上限、互斥
- 魔放/稀释机制（20%/30%/50% 等阶梯）
- 持续时间计算（回合/次数/永久）
- 免疫/解除/无视防御

### 7. command_card.md
- 5 张卡结构、洗牌规则
- 首位加成（20%/50%/80%）
- Chain 加成：Arts (NP+20%)、Buster (伤害+20%)、Quick (星+10)
- Extra Attack 触发条件
- 卡性能加成计算位置

### 8. battle_mechanics.md
- MISS 判定（基础 5% + 等级差 + 闪避）
- GUARD 判定（防御方宝具/技能/被动）
- 暴击判定（星权重、暴击率、必中/必暴）
- 即死判定（即死率、免疫、防御）
- 宝具封印、技能封印、指令封印
- 行动顺序（速度、先制攻击）

### 9. noble_phantasm_system.md
- 宝具类型（对人/对军/对城/对界/对星/对魔力/反世界/不可视）
- OC 机制（1-5 段、Correction 值）
- 宝具强化（追加效果、数值提升、OC 强化）
- 宝具连携、宝具链
- NP 回收、NP 充能

### 10. servant_ascension_skill.md
- 灵基再临：4 阶段、素材、立绘变化、开放技能/宝具强化
- 技能强化：10 级、素材、CD 变化、效果提升
- 追加技能：6 个通用、解锁条件、等级效果
- 宝具强化：任务条件、效果变化
- 灵衣/概念礼装/指令纹章

### 11. enemy_ai.md
- 气槽机制（Break 后行动模式变化）
- 行动权重（技能/宝具/普通攻击）
- 特殊行为（充能、特定条件触发、脚本战）
- 常见 AI 模式（单体/全体、优先目标）
- EnemyBuffSystem（永久/临时、不可解除）

### 12. class_affinity.md
- 职阶克制矩阵（常规七骑 + Extra 职阶 + Beast）
- 阵营克制（天/地/人/星/兽）
- 特殊克制（Berserker 1.5/2.0、Ruler 0.5/1.1、Alterego 等）
- 兽阶从者双向克制表
- 克制叠加计算（乘法）

### 13. constants.md
- 基础数值：星级基础属性、成长曲线、COST 表
- 伤害上限：单次/单卡/总计
- NP 上限：200/300/500%
- 暴击星上限：99/200/500
- Buff 上限：攻防 3000%、NP 获得 3000%、星获取 3000%
- 职阶基础系数：攻击/防御/NP/星/生成
- 等级经验表：1-120 累计经验
- 羁绊经验表：1-15 累计经验

## 数据来源优先级
1. 官方文档 / Wiki 整理
2. Atlas Academy API 实测
3. 社区验证数据
4. 理论推导（标注为理论值）

## 更新规范
- 文件头部标注：`> 最后更新：YYYY-MM-DD | 来源：xxx | 游戏版本：x.x.x`
- 重大公式变更需保留旧版本对比

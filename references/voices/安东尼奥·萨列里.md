# 安东尼奥·萨列里 - 语音

- **生日**: 别靠近我。

- **活动举行中**: 下达命令吧，御主。 
现在我会听从你的指示。

只要能允许我杀人，我就会助你一臂之力。
- **对话 3**: 咯咯。 
小心点，御主。 
我乃死。每当我使用力量，你会更为靠近黑暗深渊。

喜欢音乐。 
这些都是真正神圣的存在。 
…………对曾经的萨列里来说。

- **牵绊Lv.1**: 你召唤的从者是……啊啊，不是萨列里。 
安东尼奥·萨列里死了。 
确实死了。 
不要搞错了。
- **牵绊Lv.2**: 萨列里…… 
作为音乐家备受人们尊敬，收了众多音乐家及他们的子嗣当弟子。 
哼。只是个普通的人类。

两人克服了不和，缔结了切实的友情。是真的。 
但是……受神宠爱之人，与普通的人类，可能成为真正的朋友吗？ 
不明白。 我，不明白……

这不是事实，是虚伪，是传言。 只是可怕而卑鄙充满恶意的诽谤中伤罢了…… 
是足以撕裂一个普通人精神的尖锐匕首。 
……对，是刀刃。 也是我挥舞的这黑暗之刃的雏形之一。
- **牵绊Lv.5**: 吾非萨列里。 吾，我…… 是杀了神宠爱之子的存在。 
是从人们口口相传的传说中诞生的无辜怪物， 是灰衣男子，是萨列里自我的碎片。 
也就是说…… ……也就是说，啊啊。我究竟是谁，御主啊。 
当杀掉了应杀之人的时候，你会如何回答我呢。
- **对话 4**: 我曾经承蒙您兄长的……关照吗…… 
不，我…… 
噢噢，我…… 
究竟是谁……？
- **对话 5**: ……节奏不合。
- **对话 6**: ……看来有一些节奏比较合拍的人呢。
- **对话 7**: 阿马德乌斯·沃尔夫冈·莫扎特！ 
——吾乃杀害你之人。 
将你的名誉、你的曲子、你的痕迹全部消灭殆尽。 
这次，我一定要亲手杀了你。
